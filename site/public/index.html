Arch 桌面，一键装上

从真实华硕 / 通用 Hyprland 工作站提炼的模块集。复制命令，装完再按需合并快捷键与 Waybar。

curl -fsSL https://arch.vimalinx.com/install | bash

缺 git 等依赖时会自动 sudo pacman/apt/dnf 安装，并提示输入管理员密码。

非交互：HF_YES=1 curl -fsSL https://arch.vimalinx.com/install | bash

强制通用电源栈：HF_PROFILE=generic HF_YES=1 curl -fsSL https://arch.vimalinx.com/install | bash

若管道导致密码难输，可用：bash <(curl -fsSL https://arch.vimalinx.com/install)
