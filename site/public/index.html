HyprFlux

Full Arch Hyprland desktop, one command

Turns a minimal Arch install into a JaKooLit-based Hyprland desktop, then overlays HyprFlux modules (ASUS or generic). Copy, run, reboot, log in.

bash <(curl -fsSL https://arch.vimalinx.com/install)

Recommended form above keeps sudo / yes-no prompts on a real TTY.

Missing git and other basics are installed automatically (sudo password required).

China networks: auto-falls back to GitHub mirrors; force with HF_CN=1 bash <(curl -fsSL https://arch.vimalinx.com/install)

Pipe form: curl -fsSL https://arch.vimalinx.com/install | bash

Non-interactive: HF_YES=1 bash <(curl -fsSL https://arch.vimalinx.com/install)

Force generic power stack: HF_PROFILE=generic HF_YES=1 bash <(curl -fsSL https://arch.vimalinx.com/install)
