Arch 桌面，一键装上

从真实华硕 / 通用 Hyprland 工作站提炼的模块集。复制命令，装完再按需合并快捷键与 Waybar。

bash <(curl -fsSL https://arch.vimalinx.com/install)

推荐上面这行：确认提示和 sudo 密码都会走真实终端，不会被管道误触退出。

缺 git 等依赖时会自动安装，并提示输入管理员密码。

等价写法：curl -fsSL https://arch.vimalinx.com/install | bash

非交互：HF_YES=1 bash <(curl -fsSL https://arch.vimalinx.com/install)

强制通用电源栈：HF_PROFILE=generic HF_YES=1 bash <(curl -fsSL https://arch.vimalinx.com/install)
