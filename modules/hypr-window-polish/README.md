# Hypr Window Polish

Selected Hyprland window and layer rules extracted from the source desktop without copying the full private window-rule file.

## Included Rules

- Fullscreen windows inhibit idle.
- Picture-in-picture floats, pins, keeps aspect ratio, and moves to the top-right area.
- Common file/dialog windows float and center.
- Multimedia video windows avoid blur.
- Foot terminals disable blur.
- Rofi, notifications, and Quickshell overview layers get blur.
- Scaling/XWayland and workspace swipe settings are captured as optional snippets.

## Apply

Copy only the snippets you want into your Hyprland user config.

These rules are intentionally partial. The source workstation has a much larger app taxonomy, but that is better kept private/local.
